# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously at TestMind. If you discover a security vulnerability, please follow these steps:

1. **DO NOT** create a public GitHub issue
2. Email security@testmind.io with details
3. Include:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Security Measures

- All dependencies are regularly updated
- Security scanning with npm audit
- Code review for all PRs
- Automated security testing in CI/CD

## Response Time

- Critical vulnerabilities: 24 hours
- High severity: 3 days
- Medium/Low: 7 days

Thank you for helping keep TestMind secure!
